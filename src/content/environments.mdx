## Known Limitations in Testnet MVP

1. **Claims Dispute Settlement:** Claims and protracted default transitions are fully tracked off-chain in the database; automated on-chain execution of settlement transfers from liquidity pools is undergoing final hardening.
2. **Payment Truth Oracle:** The pilot uses `ManualPaymentAttestation.sol` for payment verification; automated zkTLS (Reclaim Protocol) bank-feed integration is in active testing.
3. **Condition Fee Lever:** Protocol fees can be configured via `setConditionFee` on `TradeInvoiceResolver`, but fee collection on testnet escrows is set to zero for partner testing.
